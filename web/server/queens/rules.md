## ドパクイーンのルール

N×N の盤面が N 個の色の領域に分かれている。次の条件をすべて満たすように **N 個の
♛（クイーン）** を置けばクリア。

1. **各行**にちょうど 1 つ
2. **各列**にちょうど 1 つ
3. **各色の領域**にちょうど 1 つ
4. クイーン同士は**隣り合わない** — 縦・横だけでなく**斜め**に接するのも禁止

どの盤面も答えはちょうど 1 通り。勘に頼らず、論理だけで必ず解ける。

## 操作

| 操作                | 動き                                        |
| ------------------- | ------------------------------------------- |
| マスをタップ        | 空 → × → ♛ → 空 の順に切り替わる            |
| 空マスからドラッグ  | なぞった空マスに × を連続で置く             |
| ↶ 戻す / ⟲ リセット | 1 手戻す / 盤面を空にする                   |
| 自動 ×              | ♛ を置くと、置けなくなったマスに × を付ける |
| 🔊                  | 効果音のオン・オフ                          |

× は「ここには置けない」というメモで、判定には関係ない。ルールに反する ♛ は赤い
縞模様で知らせる。

## ステージ

ステージ 1–2 は 5×5、そこから 6×6、7×7… と大きくなり、最大 10×10。盤面は
ステージ番号から決まるので、同じステージは誰が遊んでも同じ問題になる。クリアすると
次のステージが開く。進み具合はブラウザに保存される。

## 解き方のコツ

- **1 マスだけの領域**や、**1 行・1
  列に収まっている領域**から攻める。その行（列）の 他のマスは全部 × にできる。
- 2 つの領域が**同じ 2 行**に収まっているなら、その 2 行の他の領域のマスはすべて
  ×。 3 つなら 3 行、と一般化できる。
- あるマスに ♛ を置くと**ある領域のマスが全部 × になってしまう**なら、そのマスは
  × にできる。

## 演出について

置いた ♛ の数が増えるほど、背景・パーティクル・揺れ・音がどんどん派手になる。
残り 1 つで「ONE MORE!!」。クリアすると全部が爆発する。

BGM は序盤はオルゴールののんびりした曲。♛ が半分そろうと王道進行の速い曲に
切り替わり、1 つ置くごとにパッド・メロディ・アルペジオ・ギター・ストリングスと
和音が重なって豪華になっていく。
