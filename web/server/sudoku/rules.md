## 数独のルール

マスに数字を書き込んで盤面を埋める。次の条件をすべて満たせばクリア。

1. **各行**に 1〜N が 1 つずつ
2. **各列**に 1〜N が 1 つずつ
3. **各ブロック**（太線で囲まれた区画）に 1〜N が 1 つずつ

最初から入っている黒い数字はヒント。どの盤面も答えはちょうど 1
通りで、勘に頼らず論理だけで必ず解ける。

## 操作

| 操作         | 動き                                                     |
| ------------ | -------------------------------------------------------- |
| マスをタップ | そのマスを選ぶ（同じ行・列・ブロックと同じ数字が光る）   |
| 数字ボタン   | 選んだマスに数字を書く。ボタンの小さな数字は残りの個数   |
| ✎ メモ       | 数字ボタンが「メモ」になる。候補を小さく書き込める       |
| ⌫ 消す       | 選んだマスのメモを消す                                   |
| 候補を全部   | 空いているマスに、盤面から考えられる候補を全部メモする   |
| ↶ 戻す       | 1 手戻す                                                 |
| 🔊 / ♪ BGM   | 効果音 / BGM のオン・オフ                                |
| キーボード   | 数字・矢印キー・Backspace（メモ消し）・M（メモ）・Ctrl+Z |

正しい数字を書くと、同じ行・列・ブロックのマスからその数字のメモは自動で消える。

## ハート

ステージは **❤ 3 つ**で始まる。数字は書いたその場で判定され、

- 正しければ数字が残る。
- 間違っていれば **❤ が 1 つ減り**、数字は消える。
- ❤ が 0 のときに間違えると **ゲームオーバー**。「もう一度」で同じステージを
  最初からやり直せる。

なので盤面にある数字はいつも正しい。

## ステージ

ステージ 1 は 4×4（2×2 ブロック）、2–3 は 6×6（2×3 ブロック）、4 から 9×9。 9×9
はヒント 40 個から始まり、ステージが進むごとに減って難しくなる。盤面は
ステージ番号から決まるので、同じステージは誰が遊んでも同じ問題になる。クリアすると
次のステージが開く。進み具合はブラウザに保存される。

## 解き方のコツ

- **あと 1 つだけ空いている**行・列・ブロックから埋める。
- ある数字について、ブロックの中で**入れられるマスが 1 つしかない**ならそこ。
- あるマスについて、行・列・ブロックを見て**入れられる数字が 1
  つしかない**ならそれ。
- 詰まったら「候補を全部」でメモを出し、候補が 1 つのマスを探す。

## 演出について

マスが埋まるほど、背景・パーティクル・揺れ・音がどんどん派手になる。行・列・
ブロックを埋め切ると、その列を虹色の連鎖が走る。同時に 2 つ 3 つ埋めれば
DOUBLE・TRIPLE。残り 1 マスで「ONE MORE!!」。クリアすると全部が爆発する。

BGM は序盤はオルゴールの考えごとの曲。半分埋まると速い曲に切り替わり、
埋めるほどパッド・メロディ・アルペジオ・ギター・ストリングスと和音が重なって
豪華になっていく。
